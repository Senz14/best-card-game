**Emberfall Duel** — an original two-duelist card game that plays offline in a desktop browser from its own static files. Duel The Ashen Warden: spend growing Ember on creatures and spells from a 24-card deck, trade on the table, and burn the Warden from 20 health to 0. Guard creatures must be attacked first, Spark effects fire as creatures land, and the Warden answers with an AI of its own. Title screen, full table with both hands and life totals, and win and loss screens included.

## Run it

```sh
node serve.ts          # then open http://localhost:8080
MAKEFUN_OUTPUT_DIR=out node main.ts   # hand-in: copies game/ + screenshots/ and writes dossier.json
```
